## 🔄 User Flow Diagram

```
START
  ↓
[Home Page] → See 12 Products
  ↓
Click Product → [Product Details Page]
  ↓
Review Details & Ratings
  ↓
[+ Quantity] → [Add to Cart] ← Add More Products
  ↓
[Cart Icon] → [Shopping Cart]
  ↓
[Proceed to Checkout] → [Checkout Page]
  ↓
Enter Address & Payment Method
  ↓
[Place Order] → [Order Confirmation]
  ↓
[My Orders] → View Order Status
  ↓
Receive Product ✅
```

```

  │
  └→ [Orders] → Update Order Status

      View All Customer Orders
```

## 🚀 First-Time User Journey

1. **Open App** → See Home Page with 12 products
2. **Browse** → Scroll through product cards
3. **Search/Filter** → Find specific products
4. **Click Product** → View beautiful product details
5. **Read Reviews** → See customer feedback
6. **Add to Cart** → Add items
7. **View Cart** → Review items
8. **Checkout** → Enter shipping info
9. **Place Order** → Create order
10. **View Orders** → Track purchase

---

**All pages are fully responsive and work on mobile, tablet, and desktop! 📱 💻**
