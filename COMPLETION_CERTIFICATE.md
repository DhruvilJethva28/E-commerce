## 🚀 How to Use

### **3-Step Quick Start**

**Step 1: Backend** (Terminal 1)
```bash
cd backend
npm run dev
```

**Step 2: Database** (Terminal 2)
```bash
cd backend
npm run seed
```

**Step 3: Frontend** (Terminal 3)
```bash
cd frontend
npm start
```

**Result**: 12 Products visible on http://localhost:3000 ✅
