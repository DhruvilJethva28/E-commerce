## 🚀 Quick Command Reference

```bash
# Start Backend (Terminal 1)
cd backend && npm run dev

# Seed Database (Terminal 2)
cd backend && npm run seed

# Start Frontend (Terminal 3)
cd frontend && npm start
```

Then open: **http://localhost:3000**
